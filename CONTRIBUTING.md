# Contributing

**This is a personal fork, maintained by one person for daily use on my own phone.**
Issues and pull requests are read when there is time, but there is **no response commitment** and
many PRs will be declined simply to keep the diff against the base small.

## Reporting a bug

- **Bug in this fork** (something the base does not have): open an issue here. Please include the
  app version, Android version, device model, and the exact steps.
- **Bug that also exists in upstream Termux**: report it to
  [upstream](https://github.com/termux/termux-app/issues) instead — this fork does not track or
  forward upstream issues.

## Pull requests

Small, focused changes are welcome. Keep in mind:

- The fork stays close to its base; a change that is large or that the base could accept is likely
  to be declined here.
- One change per PR, with a message that explains *why*.
- If a change is merged, it is published under the same license as the project (GPLv3 only).
